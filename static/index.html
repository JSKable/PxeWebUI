                    Proxmox & Network Boot Client Guide
                

                

                    PxeWebUI operates using ProxyDHCP. This means you do NOT need to modify your main router or home network settings. When a client boots over PXE, your main router issues the standard IP address, and PxeWebUI responds concurrently on port 67/4011 with the bootloader file!
                


                

                    

                        

                            
                            How to Boot a Physical Machine
                        

                        
    
                            
  1. Connect the machine to the same network (Ethernet cable recommended).
    2. 
                            
  2. Power on and press the Boot Menu key (F12, F11, F8 or Esc).
    3. 
                            
  3. Select Network Boot / Onboard NIC / IPv4 PXE.
    4. 
                            
  4. The machine will load iPXE and display your customized PxeWebUI boot menu!
    5. 
                        

                    


                    

                        

                            
                            UEFI & Secure Boot Compatibility
                        

                        
    
                            
  • Legacy BIOS: Boots via undionly.kpxe + Syslinux memdisk.
    • 
                            
  • UEFI x86_64: Boots via ipxe.efi with HTTP sanboot.
    • 
                            
  • Secure Boot: Compatible via Microsoft-signed shim + GRUB chainloader.
    • 
                            
  • Windows Installers: Uses wimboot to load WinPE over network.
